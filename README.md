# THERMOREL

A five-round hidden-timer arcade game. Start the clock, then stop as close as possible to the target after the clock disappears.

## GitHub Pages deployment

This repository includes a GitHub Actions workflow. After it is pushed to GitHub, open **Settings → Pages** and choose **GitHub Actions** as the source once. Every push to `main` will then publish the site automatically.

No build step is required: open `index.html` locally, or use the published GitHub Pages URL.
